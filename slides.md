## How to Present a Lesson

Each lesson is its own Slidev deck. From the `slides/` folder:

```bash
npx slidev <deck>.md          # live presentation
npx slidev export <deck>.md   # PDF / PPTX export
npx slidev build <deck>.md    # static site build
```

<kbd>space</kbd> or <kbd>→</kbd> advances a slide; clickable answers appear with clicks.
