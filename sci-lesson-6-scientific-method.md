## Learning Objective

---

## The Scientific Method

| Step        | What happens                                                       |
| ----------- | ------------------------------------------------------------------ |
| Observation | Spot patterns, trends, or anomalies in data.                      |
| Question    | Ask a specific, testable question based on observations.          |
| Hypothesis  | Offer a testable possible explanation.                            |
| Experiment  | Run a controlled test, varying one factor at a time and measuring outcomes. |
| Conclusion  | Analyze results to see if they support the hypothesis, contradict it, or prompt new questions. |

---

## Hypothesis

- A **hypothesis** is a **testable** and **falsifiable** prediction based on observations.
- It is **not** a random guess: it is something you can test with an experiment, and the data will either support it or not.
- Written as an "**if... then...**" statement:
  - *If* the ramp is longer, *then* the ball will roll farther.

---

## Hypothesis or Not?

Which of these is a **hypothesis**?

<v-clicks>

- "If the ramp is made steeper, then the ball rolls farther." → **hypothesis** (testable, "if... then...")
- "This arrow flies the most nicely of all." → **not a hypothesis** (an opinion — we cannot test "nicely")
- "If the mass of the cart is greater, then it takes longer to stop." → **hypothesis** (testable, "if... then...")

</v-clicks>

## Variables

<v-clicks>

- Independent Variable: The variable you change on purpose. Plotted on the x-axis.
- Dependent Variable: The variable you measure. Plotted on the y-axis.
- Control Variable: A variable kept constant.
- Control Group: The group that does not receive the treatment; used as a baseline for comparison.
- Experimental Group: The group that receives the treatment or independent variable.

</v-clicks>

---

## Why Control Variables?

To run a **fair** and **repeatable** test, keep every other variable the same:

<v-clicks>

- Only the **independent variable** changes, so a change in the **dependent variable** can be traced to that one change.
- If several things changed at once, you could not tell which one caused the result.
- Another person in a different lab can repeat the test and get the same result.

</v-clicks>

---

#### Example: A student drops a ball from different heights and measures how high it bounces.

| Step | In this case                                               |
| ---------------------- | ---------------------------------------------------------- |
| Question               | Does the drop height affect how high the ball bounces?     |
| Hypothesis             | If the ball is dropped from a greater height, then it will bounce higher. |
| Independent variable   | drop height (what we change)                               |
| Dependent variable     | bounce height (what we measure)                            |
| Control variable       | the **same ball** (kept the same)                          |
| Experimental group     | the drop from a **higher** height (gets the change)        |
| Control group          | the drop from the **original** height (baseline)           |

---

## Check: Experimental or Control?

A student tests how the battery voltage affects the brightness of a lamp. Some lamps run at the original voltage; the same kind run at a higher voltage.

<v-clicks>

- Experimental group: the lamps at the **higher voltage** (the change is applied).
- Control group: the lamps at the **original voltage** (baseline).
- What we compare: the brightness of the two groups.

</v-clicks>

---

## After the Experiment

<v-clicks>

- Compare data against your hypothesis.
- Was the hypothesis supported or not supported?
- A conclusion states what the evidence showed — even if the hypothesis was wrong.

</v-clicks>

---

## Summary

- The **scientific method**: Observation → Question → Hypothesis → Experiment → Conclusion.
- A **hypothesis** is a testable "if... then..." prediction — based on observations, **not** a random guess.
- **Independent variable** = what you change; **dependent variable** = what you measure; **control variables** = what you keep the same.
- A **control group** is the baseline; the **experimental group** gets the change.
