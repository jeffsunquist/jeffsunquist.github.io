## Kinematics Variables and Symbols

| Quantity          | Symbol    | Units | Type |
| ----------------- | --------- | ----- | ---- |
| **position**          | $x$       | $\mathrm{m}$ | vector → |
| **distance**          | $d$       | $\mathrm{m}$ | scalar |
| **displacement**      | $\Delta x$ | $\mathrm{m}$ | vector → |
| time              | $t$       | $\mathrm{s}$ | scalar |
| speed             | $s$       | $\frac{\mathrm{m}}{\mathrm{s}}$ | scalar |
| velocity          | $v$       | $\frac{\mathrm{m}}{\mathrm{s}}$ | vector → |
| acceleration      | $a$       | $\frac{\mathrm{m}}{\mathrm{s}^2}$| vector → |
