## Distance vs Displacement

| Distance                        | Displacement                          |
| ------------------------------- | ------------------------------------- |
| total path length               | change in position                    |
| scalar (no direction)           | vector (magnitude + direction)        |
| never negative                  | can be positive, negative, or zero    |
| depends on the route taken      | depends only on start and finish      |
