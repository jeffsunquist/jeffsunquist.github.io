## Static Friction

- **Static friction** holds a stationary object in place.
- It **matches** the applied force, up to a maximum, so the object does not move.

((static_friction_push: a person pushing a heavy crate that has not moved, with the push arrow and a static friction arrow of equal length))

> [!IMPORTANT]
> The **coefficient of friction ($\mu$)** is a number describing how grippy two surfaces are. It has **no units**.
