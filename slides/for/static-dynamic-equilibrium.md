## Static and Dynamic Equilibrium

- **Static equilibrium**: the object is **at rest**.
- **Dynamic equilibrium**: the object moves at a **constant velocity**.

<center>

((static_vs_dynamic: a book at rest beside a skydiver falling at terminal velocity))

</center>

| | Static | Dynamic |
| --- | --- | --- |
| velocity | zero | constant, nonzero |
| acceleration | zero | zero |
| net force | zero | zero |
