## Which Forces Have an Equation?

| Force | How you find its value |
| --- | --- |
| weight $F_g$ | $F_g = mg$ |
| friction $F_f$ | $\lvert F_f\rvert = \mu \lvert F_N \rvert$ |

All other forces must either be given, or found algebraically using $F_{net}=\mathrm{sum\,of\,individual\,forces}$
