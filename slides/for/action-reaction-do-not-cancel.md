## Why Action–Reaction Pairs Don't Cancel

- The two forces act on **different objects**, so they never cancel.
- Only forces acting on the **same** object can be combined into a net force.

((action_reaction_not_cancel: a book on a table with the pair "book pushes table / table pushes book" beside "Earth pulls book / book pulls Earth", each pair split across two objects))

| Wrong | Right |
| --- | --- |
| "the pairs cancel, so nothing moves" | each object feels only **one** force from the pair |
