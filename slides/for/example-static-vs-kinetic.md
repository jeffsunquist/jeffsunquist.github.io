## Example: Static vs Kinetic Friction

A $\overset{m}{\underline{10\ \mathrm{kg}}}$ crate sits on a floor with $\mu_s = 0.5$ and $\mu_k = 0.4$.

<v-clicks>

**Solution**

The normal force balances the crate's weight:

$F_N = mg = (10\ \mathrm{kg})(9.8\ \mathrm{\frac{m}{s^2}}) = 98\ \mathrm{N}$

Maximum static friction:

$F_{s,\max} = \mu_s F_N = (0.5)(98\ \mathrm{N}) = 49\ \mathrm{N}$

Kinetic friction:

$F_k = \mu_k F_N = (0.4)(98\ \mathrm{N}) = 39.2\ \mathrm{N}$

- A $30\ \mathrm{N}$ push: static friction is $F_s = 30\ \mathrm{N}$, so the crate **stays at rest**.
- A $60\ \mathrm{N}$ push: it exceeds $49\ \mathrm{N}$, so the crate **slides** with $F_k = 39.2\ \mathrm{N}$.

</v-clicks>
