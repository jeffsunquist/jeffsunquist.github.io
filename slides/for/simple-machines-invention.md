## Simple Machines in Action

> [!NOTE]
> Design an **invention** that uses one or more simple machines to make work easier. Build it, test it, then improve it.

((design_cycle: the design loop — ask, imagine, plan, build, test, improve))

- A machine changes the size or direction of a force, but it does **not** reduce the total work done.
- Simple machines can be **combined** into one device.
