## Forces Vocabulary

| Term | Meaning |
| --- | --- |
| **scalar** | a quantity with magnitude only — e.g. mass |
| **vector** | a quantity with magnitude and direction — e.g. force |
| **magnitude** | how large a force is, measured in newtons (N) |
| **direction** | the way a force points, e.g. up, down, left, right |
| **force** | a push or a pull |
| **net force** | the sum of all forces acting on an object |
| **free-body diagram** | one object drawn as a dot, with every force on it as a labeled arrow |
| **balanced / unbalanced** | net force zero / net force not zero |
