# Physics Lesson Slides

G6–G7 Physics lesson decks built with [Slidev](https://sli.dev).

Visit the site at **https://www.basado.org/**

Each lesson deck is served at `/<deck>/` (e.g. `/sci-lesson-1-observations/`),
with a landing `index.html` at the root. The decks are built and published
automatically by the Pages workflow in `.github/workflows/deploy.yml` — just
commit and push to `main`.
